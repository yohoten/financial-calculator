# 货币时间价值与资本成本计算器

> 对应课程第 3 章（货币时间价值）与第 4 章（资本成本）
> 技术栈：Python + pandas + numpy + matplotlib（另含 tkinter 图形界面）
> 实测运行环境：**Python 3.9.13 / numpy 2.0.2 / pandas 2.3.3 / matplotlib 3.9.4 / openpyxl 3.1.5 / Pillow 11.3.0 / tkinter 8.6**

一套参数化、可复用、自带三层校验与业务解读的财务计算工具。替代手工 Excel 表格，
实现复利/年金、债务/股权资本成本、WACC 的一键式批量计算与可视化。

---

## 快速开始

```bash
# 安装依赖
python -m pip install -r requirements.txt

# 交互式菜单（推荐初次使用）
python main.py

# 一键运行全部示例场景，生成图表 + Excel 汇总
python main.py --demo

# 运行测试用例（8 组，含数值断言与边界回归）
python test_cases.py

# 图形界面（tkinter）
python main.py --gui
```

Windows 下也可以直接**双击 `财务计算器GUI.pyw`** 打开图形界面（无控制台窗口）。

## 核心特性

**双引擎互验** — 债务成本用 YTM 精确法（自实现牛顿迭代 + 二分法兜底）与教材近似公式互验；
股权成本用 CAPM 与 DDM 交叉验证；年金结果与教材系数表比对；自定义现金流的"逐期滚动终值"
与"整体折现净现值"互为校验。多重独立路径验证同一结果，规避手工 Excel 的单点错误风险。

**三层参数校验** — L1 类型层（是否为空/数字）、L2 边界层（是否超出数学模型定义域）、
L3 合理性层（是否反常识）。错误提示遵循"错在哪里 + 为什么错 + 应如何修正"三段式，
可自动识别"6% 误输为 6"这类最常见口径错误；第三层"口径提示"按参数去重后只展示一次。

**口径管理** — 期间利率与年化利率通过 `periods_per_year` / `freq` 参数显式换算
（`k_年化 = (1 + k_期间)^m − 1`），业务解读必须声明所采用的口径，
**"72 法则"只在年化口径下出现**；税后债务成本的三种口径（EAR×(1−T) / 严格口径 /
教材简化）在 `freq > 1` 时会被并列给出。口径分叉是本类计算最常见的错误来源，因此在设计上被专门处理。

**业务解读引擎** — 计算结果自动附带业务解读。例如 WACC 解释包含绝对水平（与行业对比）、
相对水平（与无风险利率利差）、结构成因（各来源贡献分解）、价值创造（EVA 判断）四个维度。

**10 张专业图表** — 复利增长曲线、年金现金流时间轴、债权成本曲线、WACC 结构分解、
WACC 敏感性热力图、资本结构优化对比、还款结构图、自定义现金流序列图，以及 2 张界面截图，
配色统一、支持中文字体。

## 测试验证

运行 `python test_cases.py`，当前为 **通过 51 项 / 失败 0 项**：

| 用例 | 场景 | 验证要点 |
| --- | --- | --- |
| 1 | 个人储蓄复利增值 | 计息频率效应、EAR |
| 2 | 教育金定投 | 与教材系数表 (P/A, 5%, 10)=(F/A, 5%, 10) 比对 |
| 3 | 企业债券资本成本 | 双引擎互验 + 债券定价自洽 + **半年付息口径 + 筹资费率** |
| 4 | 上市公司股权成本 | CAPM 与 DDM 交叉验证 |
| 5 | 某公司 WACC | 贡献分解可加性 |
| 6 | 房贷还款计划 | 现值逆向校验等于本金 |
| 附加 1 | 参数校验 | 9 项异常输入识别 |
| 附加 2 | 边界输入回归 | m=0 / m=−1 / tax=1.5 / 资本总额=0 / g≥r / freq=0 等，必须是中文提示而非堆栈或静默错误 |

断言失败不会中断后续用例，末尾统一输出"通过 N 项 / 失败 M 项"并列出全部偏差明细；
全部通过时进程退出码为 0，可直接接入 CI 或批处理。
