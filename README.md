# 货币时间价值与资本成本计算器

> 对应课程第 3 章（货币时间价值）与第 4 章（资本成本）
> Python 3.11 + pandas + numpy + matplotlib

一套参数化、可复用、自带校验与业务解释的财务计算工具。替代手工 Excel 表格，
实现复利/年金、债务/股权资本成本、WACC 的一键式批量计算与可视化。

---

## 快速开始

```bash
# 安装依赖
pip3 install pandas numpy matplotlib openpyxl

# 交互式菜单（推荐初次使用）
python3 main.py

# 一键运行全部示例场景，生成 8 张图表 + Excel 汇总
python3 main.py --demo

# 运行测试用例（7 组，含数值断言验证）
python3 test_cases.py
```

## 核心特性

**双引擎互验** — 债务成本用 YTM 精确法（自实现牛顿迭代）与教材近似公式互验；
股权成本用 CAPM 与 DDM 交叉验证；年金结果与教材系数表比对。多重独立路径
验证同一结果，规避手工 Excel 的单点错误风险。

**三层参数校验** — L1 类型层（是否为空/数字）、L2 边界层（是否超出数学模型定义域）、
L3 合理性层（是否反常识）。错误提示遵循"错在哪里 + 为什么错 + 应如何修正"三段式，
可自动识别"6% 误输为 6"这类最常见口径错误。

**业务解读引擎** — 计算结果自动附带业务解读。例如 WACC 解释包含绝对水平（与行业
对比）、相对水平（与无风险利率利差）、结构成因（各来源贡献分解）、价值创造
（EVA 判断）四个维度，把数字翻译成决策语言。

**8 张专业图表** — 复利增长曲线、年金现金流时间轴、债权成本曲线、WACC 结构分解、
WACC 敏感性热力图、资本结构优化对比、还款结构图等，配色统一、支持中文字体。

## 输入口径

| 参数类型 | 输入格式 | 示例 |
| --- | --- | --- |
| 利率 / 税率 / 增长率 | **小数** | 6% 输入 `0.06` |
| 期数 / 年数 | **正整数** | 10 年输入 `10` |
| 金额 | 数值（元） | 100 万输入 `1000000` |
| 计息次数 m | 1=年 / 2=半年 / 4=季 / 12=月 | 月计息输入 `12` |
